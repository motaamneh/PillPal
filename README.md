PillPal Backend - Medication Reminder API 💊

Spring Boot backend for PillPal - a medication reminder application that helps users track their daily medications and never miss a dose.

🚀 Features

🔐 JWT Authentication - Secure user authentication and authorization
💊 Medication Management - Full CRUD operations for medications
⏰ Reminder System - Foundation for medication scheduling and notifications
📊 Progress Tracking - Daily medication adherence tracking with logs
🔄 Daily Reset - Automatic reset of medication status at midnight
📱 RESTful APIs - Clean, consistent API design for Flutter frontend
🔒 Security - Password encryption, SQL injection prevention, secure headers
🛠️ Tech Stack

Framework: Spring Boot 3.0
Language: Java 17
Database: PostgreSQL 15
Security: Spring Security + JWT
ORM: Spring Data JPA + Hibernate
Build Tool: Maven
Testing: Postman
Validation: Bean Validation API

📋 Prerequisites

Java 17 or higher
Maven 3.6+
PostgreSQL 15+
IDE (IntelliJ IDEA recommended)
